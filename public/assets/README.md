# MagickVoice documentation assets

Place captured product media in these folders:

- `screenshots/`: page screenshots. Use the doc slug as the filename, for example `dashboard.png`.
- `animations/`: short GIF or WebM clips for motion-heavy flows such as builders, dialer, uploads, and simulations.

The docs app already looks for these predictable paths and falls back to a polished placeholder when an asset has not been captured yet.
