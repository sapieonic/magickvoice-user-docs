## Manage a reusable call script

Keep voice-agent behavior organized and ready for safe use in calls and campaigns.

1. Open Voice, then Call Scripts. The count beside the heading shows how many scripts exist; each card lists the script name, its enabled language chips, and its guideline count.
2. Select Create call script to build a new script from a template or a blank canvas. Select Edit on an existing card to open the same editor for that script.
3. Use Import JSON only with a script file you have reviewed. Use Export as JSON on a card to save a script definition for transfer or backup.
4. Use Delete on a card only when the script is no longer needed. Confirm it is not selected by a live call or campaign before removing it.
